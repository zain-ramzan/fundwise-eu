# GitHub Pages Verification

On 19 August 2026, the public GitHub Pages catalogue was verified at `https://zain-ramzan.github.io/fundwise-eu/`. The published page loaded the Yorkie-blue public discovery experience, eight curated opportunity cards, official-source links, client-side search controls, and the calendar-saving chooser.

The Startup Europe calendar modal exposed pre-filled Google Calendar and Microsoft Outlook event links plus an `.ics` download action. The published static edition intentionally excludes server, database, OAuth, private application workspace, administration, and live record ingestion.

After the subsequent Pages rebuild, the public site was rechecked with a cache-busting version query. The catalogue count rendered correctly as “8 opportunities in this public snapshot,” confirming the latest static revision had propagated.

The enhanced catalogue was then tested live: selecting the **Digital & AI** sector reduced the visible catalogue from eight to three matching opportunities and announced the updated result count. The public header contains no central Discover control.

The live Share control was also verified. It opened a share chooser with a copyable catalogue link and a pre-populated email composition link containing both the opportunity reference and its official source URL.
